# 메리츠화재 GA 설계사 시상안내 카드뉴스 시스템

> Repo: https://github.com/meritzGA/cardnews

매니저가 산하 설계사에게 개인화된 시상안내 카드뉴스를 빠르게 만들고 카톡으로 발송할 수 있게 해주는 도구입니다.

## 핵심 기능

- **매니저 코드 입력** → 산하 설계사 자동 조회 (지사별 그룹 + 가나다 정렬)
- **카드뉴스 PNG 자동 생성** — 토스 스타일 디자인, 메리츠화재 컬러
  - 확정된 시상금 / 추가 받을 수 있는 시상금 듀얼 박스
  - "○만원 더하면 +○만원" 액션 배너
  - 시상금 세부 내역 (브릿지·연속가동·주차별)
  - 5~6월 추가 기회 (시책표 기반 정확한 시상금)
  - 베테랑 배지 (연속 MC 달성)
- **매니저 연락처 표시** — tel: 전화걸기 링크
- **카톡 발송용 메시지 자동 생성** — 복사 후 카톡에 붙여넣기
- **일괄 선택 → ZIP 다운로드** — 여러 설계사 카드 한 번에

## 설치

```bash
# 1) 패키지 설치
pip install -r requirements.txt

# 2) Chromium 다운로드 (Playwright 렌더용)
playwright install chromium
```

## 실행

```bash
streamlit run app.py
```

브라우저 자동 오픈 → http://localhost:8501

## 사용 흐름

1. **매니저 코드 입력** (예: `320010476`) → 조회
2. 산하 설계사 목록이 **지사별로 그룹** + **가나다 순** 표시
3. **카드보기** 클릭 → 카드 PNG + 매니저 전화 링크 + 카톡 메시지
4. **PNG 다운로드** + **메시지 복사** → 카톡에 첨부 + 붙여넣기
5. (선택) 체크박스로 여러 명 선택 → **ZIP 일괄 다운로드**

## 카드 사전 생성 (선택)

대량 카드를 미리 만들어 두려면:

```bash
python generate_fast.py
```

`cards_v2/` 폴더에 `{본인고객ID}.png` 형식으로 저장. Streamlit이 이미 만들어진 PNG를 우선 사용합니다.

## 시상금 계산 로직

### 확정 시상금
PRIZE_SUM 엑셀의 다음 컬럼 값을 그대로 사용:
- `추가13회예정금_{n}주` (n=1~4)
- `추가13회예정금_{n}주_추가` (1주차만)
- `추가13회예정금_{n}주_상품`
- `추가13회예정금_{n}주_유퍼간편`
- `추가13회예정금_주차연속가동`
- `추가13회예정금_월누계`

검증: 합산 = `추가13회예정금계 + BRIDGE.시상금합계` (오차 0)

### 5~6월 추가 기회 (시책표 기반)
대리점별 시책 JSON에서 구간 매핑:

```json
{
  "tiers": [
    {"실적": 100000, "시상": 200000},   // 10만 → 20만
    {"실적": 200000, "시상": 600000},   // 20만 → 60만
    {"실적": 300000, "시상": 800000},   // 30만 → 80만
    {"실적": 500000, "시상": 1800000}   // 50만 → 180만
  ]
}
```

- 현재 실적 → 도달 구간 → 시상금
- 다음 구간까지 부족액 + 추가 시상금 차액 계산
- **두 시상(브릿지/연속가동)은 같은 실적 풀** → max 부족액만 채우면 둘 다 충족

## 시책 추가

대리점이 표준 시책과 다른 경우 `schemes/{대리점명}.json` 추가하면 자동 매칭됩니다.
매칭 안 되면 `_default_meritz.json` 자동 적용.
